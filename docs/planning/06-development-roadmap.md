# Development Roadmap

전업 기준 약 6주. 가장 불확실한 임베드부터 검증한다.

| 단계 | 기간 | 산출물 | 완료 기준 |
|---|---|---|---|
| 1. 임베드 수직 관통 | 1주 | 로더, bootstrap, iframe, 가짜 스트림 | 외부 정적 페이지에서 스트리밍, 미허용 도메인 거부 |
| 2. 근거 답변 | 1주 | 스키마, RLS, 검색, 게이트, 검증기, 평가셋 | 평가 기준 통과, 임계값 확정 |
| 3. 위젯 완성 | 1주 | 재시도, 복원, 문의 폼, 접근성, 모바일 | axe 0건, iOS 실기기 통과 |
| 4. 관리자 | 1주 | 지식, 위젯 미리보기, 설치, 문의 | 데모 1 시나리오 완주 |
| 5. 데모·방어 | 1주 | 익명 체험, 요청 제한, 데모몰, 삭제 작업 | 한도 초과 상태 확인, 데모 2 완주 |
| 6. 마감 | 1주 | 성능 측정, 교차 브라우저, 케이스 스터디 | 측정값 기록, 영상 완성 |

## 테스트

| 종류 | 대상 |
|---|---|
| Vitest | Origin 매칭, 청크 분할, 숫자 검증기, 개인정보 마스킹, 요청 제한 |
| RLS 테스트 | 타 사용자 봇·대화 접근 차단 |
| Playwright | 적대적 CSS 호스트, 교차 origin, 중단·재시도, 가짜 LLM |
| 평가셋 40~60문항 | 지식 내, 바꿔 말한 질문, 지식 외 정책, 프롬프트 주입 |
| 수동 | iOS Safari, Android Chrome, 스크린리더 |

평가 합격선: 지식 외 질문의 지어낸 답변 0건, 지식 내 질문의 정답률 90% 이상.

## 위험

| 위험 | 대응 |
|---|---|
| 한국어 검색 품질 부족 | 2단계 평가셋으로 조기 측정, 키워드 혼합 준비 |
| 숫자 검증 오탐 (`3만원`/`30,000원`) | 표기 정규화, 애매하면 답변 대신 문의 유도 |
| 답변 교체로 인한 어색함 | 위험 문구는 문장 단위로 지연 표시하는 방안 준비 |
| 고객 사이트의 엄격한 CSP | 설치 탭에 필요한 `script-src`, `frame-src` 안내 |
| iframe 저장소 분할·Safari 제한 | 저장 실패 시 메모리로 동작, 대화 복원은 최선 노력 |
| 데모 비용 공격 | 다층 제한과 제공사 지출 한도 |
| 개인정보 규제 | 최소 수집, 마스킹, 실고객 전 법률 검토 |
