# Portfolio Strategy

## 데모

- 데모 1, 관리자: 왼쪽 FAQ, 오른쪽 위젯. "환불 며칠 안에 되나요?"에 7일로 답하게 한 뒤 FAQ를 14일로 고치고 다시 물으면 답과 출처가 바뀐다. 이어서 색상을 바꾼다.
- 데모 2, 방문자: 별도 도메인의 가상 브랜드 쇼핑몰. 정책 페이지 내용이 지식베이스와 같아 답변을 직접 대조할 수 있다. 결제는 없다.
- 데모몰 상단과 푸터에 "SupportKit 포트폴리오용 가상 쇼핑몰이며 실제 주문·결제되지 않습니다"를 고정한다. Work 항목에도 "개인 제작 제품 · 실고객 사례 아님"을 표기한다.

## Work 항목 구성

한 줄 설명, 20초 영상, 데모몰 체험·관리자 체험 링크, 문제와 해결, 기술 결정 3가지, 측정값.

## 기술 성과 (수치는 측정 후 기입)

| 주제 | 내용 |
|---|---|
| 임베드 격리 | Shadow DOM 발사 버튼과 지연 iframe, 적대적 CSS 테스트 |
| 신뢰 경계 | 공개 식별자와 서명 토큰 분리, iframe의 Origin 문제 해결 |
| 비동기 UX | 스트리밍, 중단, 재시도, 답변 교체 |
| 환각 제어 | 검색 게이트와 결정적 수치 검증, 평가셋 결과 |
| 접근성·성능 | iframe 경계를 넘는 포커스 복귀, 번들 크기, 레이아웃 이동 0 |

위시켓 고객에게는 "내 사이트에 붙는다, 없는 답을 안 만든다, 월 운영비가 얼마다"를, 채용 담당자에게는 임베드 설계와 비동기 상태 관리를 앞세운다.
