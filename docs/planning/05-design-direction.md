# Design Direction

콘셉트: **근거가 보이는 상담 창구.** 화려한 AI 표현 대신 잘 편집된 안내문처럼 보이게 한다. "AI가 똑똑하다"가 아니라 "이 답의 출처가 어디인가"를 시각적 중심에 둔다.

## 공통

- 따뜻한 무채색 바탕, 잉크색 본문, 강조색 1개. 상태 표현은 색보다 문구로 한다.
- 관리자는 Pretendard로 굵기 대비를 크게 쓰고, 위젯은 번들을 위해 시스템 폰트를 쓴다.
- 그라데이션, 반짝이 아이콘, 반복 카드 그리드를 쓰지 않는다.

## 위젯

- AI 답변은 말풍선 없는 본문, 방문자 메시지만 옅은 색 면으로 구분한다.
- 출처는 답변 아래 각주처럼 표시하고 펼치면 원문이 보인다.
- 가짜 타자 효과 없이 실제 단계("안내 문서 확인 중")를 보여준다.
- "못 찾음"은 오류가 아니라 다음 행동(문의 남기기)이 있는 정상 상태로 디자인한다.
- 발사 버튼은 텍스트 알약형을 기본으로 한다.
- 운영자가 어떤 색을 골라도 OKLCH로 대비 4.5:1을 자동 보정한다.
- 모바일은 전체 화면, `visualViewport`로 키보드 대응, 입력 글자 16px.
- Esc로 닫으면 발사 버튼으로 포커스가 돌아온다. `prefers-reduced-motion`을 지킨다.

## 관리자

- 카드 대신 밀도 있는 목록과 상세. 문의 탭은 `j/k` 키 이동을 지원한다.
- 숫자는 한 줄만 쓴다: "확인할 문의 3건".
- 빈 상태는 다음 행동을, 오류 상태는 복구 방법을 보여준다.

## 성능 예산

로더 5KB gzip 이하, 패널 80KB gzip 이하, 고객 페이지 레이아웃 이동 0.
