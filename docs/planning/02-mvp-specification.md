# MVP Specification

## P0: 반드시 구현

| 기능 | 완료 기준 |
|---|---|
| 외부 설치 | 별도 도메인의 순수 HTML 사이트에서 스크립트 한 줄로 동작 |
| 격리 | `* { all: unset !important }` 같은 적대적 CSS 페이지에서도 위젯이 깨지지 않음 |
| 도메인 검증 | 미허용 Origin은 bootstrap 거부, 미허용 사이트의 iframe 삽입 차단 |
| 스트리밍 채팅 | 중단, 실패, 입력 보존 재시도, 24시간 내 대화 복원 |
| 지식베이스 | FAQ와 붙여넣은 텍스트의 CRUD, 저장 후 다음 질문부터 반영 |
| 근거 기반 답변 | 지식베이스 밖의 정책 질문에서 지어낸 답변 0건(평가셋 기준), 답변에 출처 표시 |
| 위젯 설정 | 이름, 색상, 환영 문구, 위치, 시작 질문이 미리보기에 즉시 반영 |
| 문의 접수 | 개인정보 동의 후 접수, 운영자 이메일 알림, 상태 변경 |
| 대화 관리 | 답변 결과별 필터, "FAQ로 추가" |
| 설치 안내 | 코드 복사, 허용 도메인, 실제 설치 감지 표시 |
| 권한 분리 | 테넌트 간 접근 차단 자동화 테스트 통과 |
| 비용 제어 | 세션·IP·봇·전역 제한이 동작하고, 한도 초과 상태가 디자인되어 있음 |
| 데이터 수명 | 보존 기간 경과분 자동 삭제, 운영자가 대화 삭제 가능 |
| 접근성·모바일 | 키보드만으로 전체 사용 가능, axe 위반 0건, 실기기 iOS Safari 확인 |

## 나머지 분류

| 분류 | 항목 |
|---|---|
| P1: 완성도 | 답변 평가 버튼, 시작 질문 답변 캐시, 키워드 검색 혼합, 이메일 로그인 |
| 후속 버전 | 실시간 상담원 연결, PDF 업로드, URL 크롤링, 팀 권한, 결제, 다국어, 주문 조회 연동 |
| 비용 발생 | LLM 사용량, 임베딩, 메일 발송, 실고객 운영 시 호스팅, 도메인 |
| 가치 대비 낮음 | 통계 대시보드, 위젯 크기 자유 조절, 스트리밍 Markdown 전체 지원, 다중 LLM 선택 UI |

실시간 상담원 연결은 MVP에서 제외한다. 상담원 접속 상태, 배정, 응대 공백 처리가 함께 필요한데 소규모 사업자는 상담원이 상시 대기하지 않는 경우가 많다. 문의 접수와 메일 알림으로 대체한다.
