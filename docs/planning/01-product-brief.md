# Product Brief

SupportKit(가칭)은 코드를 모르는 운영자도 자기 웹사이트에 설치하고, 등록한 정보 안에서만 답하는 AI 상담 위젯이다.

## 고객

- 1차: 문의가 반복되는 소규모 쇼핑몰·브랜드
- 2차: 고객사에 납품할 웹에이전시·외주 개발사

## 핵심 가치

- `<script>` 한 줄로 어떤 사이트에도 설치
- 근거가 없으면 답하지 않음
- 코드 수정 없이 FAQ를 고치면 답변이 바뀜
- AI가 해결하지 못한 건은 운영자에게 넘어감

## 경쟁 서비스

| 서비스 | 과금 구조 | SupportKit의 위치 |
|---|---|---|
| Intercom Fin | 해결 건당 $0.99 | 기능으로 경쟁하지 않음 |
| Tidio Lyro | 대화 건 단위 | 대화량이 많을수록 구축형이 유리해질 수 있음 |
| Chatbase | 메시지 크레딧 (출처별 수치 상이) | 범용 챗봇 빌더 |
| 채널톡 ALF | 요금 미확인 | 국내 강자이자 통합 CS 제품 |

## 차별점: 고객 소유 구축형

1. 코드, 데이터, LLM 키를 고객이 소유한다.
2. 금액·기간을 코드로 검증해 지어낸 답을 막는다.
3. "못 답한 질문을 FAQ로 등록"하는 개선 흐름이 제품의 중심이다.

## 이 MVP가 완성해야 하는 것

설치, 답변, 실패 처리, 개선, 운영 통제가 하나로 이어진 흐름을 실제 외부 사이트에서 완성해야 단순 API 데모가 아닌 웹 솔루션이 된다.

1. 남의 사이트에서 실제로 동작한다. 별도 도메인의 일반 HTML 사이트에 한 줄로 설치되고, CSS·JS 충돌 없이 작동하며, 서버가 허용 도메인을 검증한다.
2. 모르면 모른다고 답한다. 등록하지 않은 환불·배송 규정을 만들지 않으며, 평가셋 수치로 증명한다.
3. 운영자가 개발자 없이 바꾼다. FAQ 수정이 다음 답변에 반영되고, 디자인 변경이 실제 위젯 미리보기에 바로 보인다.
4. AI가 끝내지 못한 건이 사람에게 넘어간다. 동의 후 문의 접수, 운영자 알림, 상태 관리, FAQ 보강까지 이어진다.
5. 운영해도 사고가 나지 않는다. 고객별 데이터 분리, 비밀키 비노출, 요청 제한, 비용 상한, 보존·삭제 정책이 동작한다.
